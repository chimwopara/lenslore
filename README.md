# LensLore Photography Portfolio

Professional photography portfolio website with hierarchical folder navigation, dark mode, and booking system.

## File Structure

```
root/
├── index.html              # Main HTML file
├── README.md               # This file
├── src/images/Background/             # Background images (create this)
│   ├── hero.jpg
│   ├── pricing.jpg
│   ├── aboutme.jpg
│   └── getintouch.jpg
├── src/images/     # Photo albums (create this)
│   ├── Brands & Campaigns -- Fashion & Lifestyle/
│   ├── Brands & Campaigns -- Organizations/
│   └── Personal Branding/
└── src/                    # Source files
    ├── css/
    │   └── styles.css      # All styles
    ├── js/
    │   ├── gallery.js      # Portfolio navigation
    │   ├── modal.js        # Booking modal
    │   └── theme.js        # Dark mode & UI
    └── data/
        └── portfolio.js    # Portfolio structure
```

## Setup Instructions

1. Place all files in your root directory
2. Create `Background` folder with 4 images (hero.jpg, pricing.jpg, aboutme.jpg, getintouch.jpg)
3. Create `src/images` folder with your photo albums matching the exact structure
4. Open index.html in a web browser

## Features

- ✨ Hierarchical folder navigation
- 🌙 Dark mode toggle
- 📱 Mobile responsive
- 🎨 Clean, modern design
- 📸 Lightbox image viewer
- 📋 PDF invoice generation
- 💼 Package booking system
